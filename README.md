# Time tracker

Личный трекер дня: план пишется накануне, утром день стартует и план замораживается,
в течение дня блоки трекаются таймером, вечером — итог и сводка для стендапа.

## Стек

Nuxt 4 (Vue 3 + TypeScript) · Postgres 17 · Drizzle ORM · Tailwind 4

## Запуск

```bash
cp .env.example .env
docker compose up -d      # Postgres на порту 5433
npm install
npm run db:push           # накатить схему
npm run dev               # http://localhost:3000
```

## Структура

```
app/pages/          страницы (файл = адрес)
app/components/     Vue-компоненты
server/api/         HTTP-эндпоинты
server/utils/       схема БД и запросы
shared/utils/       код, общий для фронта и сервера
```

## Аккаунты и доступ

Каждый ведёт свои дни. Чтобы коллега видел твой прогресс:

1. Он регистрируется в приложении.
2. На странице «Друзья» кто-то из вас вводит почту другого — уходит заявка.
3. Второй её принимает.
4. Дальше день друга открывается по ссылке из списка друзей: всё видно,
   изменить ничего нельзя, комментировать можно — к отдельным блокам и ко дню целиком.

Право на запись проверяется на сервере в каждом эндпоинте, а не только скрытыми кнопками.

## Деплой

Нужны два аккаунта: хостинг (Vercel) и облачный Postgres (Neon).

1. Завести базу на neon.tech, скопировать строку подключения.
2. Залить репозиторий на GitHub, импортировать его в Vercel.
3. В настройках проекта Vercel добавить переменные `DATABASE_URL` (строка из Neon)
   и `NUXT_SESSION_PASSWORD` (случайная строка от 32 символов — ею шифруется кука сессии).
4. Накатить схему на облачную базу локально:
   `DATABASE_URL="<строка из Neon>" npm run db:push`
5. Отключить Deployment Protection в настройках проекта Vercel,
   иначе на сайт не попадёт никто, кроме владельца аккаунта.
   Вход в само приложение эту защиту заменяет.

Nuxt определяет Vercel сам, отдельная настройка сборки не нужна.

## Ключевое решение

План на день замораживается в момент «Старт дня». Всё, что заведено после этого,
помечается `is_unplanned` — иначе план задним числом подгоняется под факт
и сравнивать становится не с чем.
